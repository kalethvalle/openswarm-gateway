# Constitución de OpenSwarm — revisión 1

- IA para intención y colaboración; código para contratos, permisos y límites.
- Configuración v2 gratuita: ningún fallback habilita pago automáticamente.
- Instrucciones originales y evidencia conservadas; resúmenes etiquetados.
- Herramientas externas ejecutadas por el cliente; no repetir efectos para recuperar una inferencia.
- Límites finitos de llamadas, contexto, consultas, cuotas y tiempo.
- Laya decide, no genera contexto ni prueba la veracidad del resultado.
- Medición reproducible y resultados reales; tests bloqueados no equivalen a aprobados.
- Software del Gateway MIT; modelos y dependencias conservan licencias propias.
- Una instancia con SQLite en esta versión; no prometer disponibilidad ilimitada de servicios gratuitos.
